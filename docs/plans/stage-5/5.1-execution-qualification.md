## Starting facts

Docker guardian/lease, network-isolated workers, protected mounts, scoped relay and pinned Hermes images exist. Real Git bypass and actual disposable-controller SIGKILL tests passed on WSL and OrbStack. One contained Hermes local edit passed on each. Mac uses a VM relay/socket volume and host relay; direct mounting of a Mac Unix socket failed. These facts do not qualify Codex or the production journal. The current admission planner protects nested instructions, supports only explicitly enrolled ordinary nested repositories, and rejects unenrolled nested Git, linked worktrees, symlinks, hard links and special files.
